# AI Tool Usage

AI-tools were used mainly used for debugging aids. One core challenge of re-using an existing project was that network configuration, and some other things, were misconfigured. In the process of untangling that, Claude Code and Codex were used to help understanding and to suggest fixes.

Some other occasions were the manual deployment (we used that as a first "how does the deployment work" step). Since the manual deployment has a lot of moving parts, reading in documentation couldn't solve the issues, and we used Claude Code and Codex to understand the process better.

We also used AI to understand Dependabot and Gitleaks, why they are useful, and how they fit into our existing CI/CD pipeline. It explained how a failed secret scan blocks Docker publishing and why it was important to have. 

Since the main purpose of the project was to learn about and to demonstrate a complete CI/CD pipeline, we think that using AI-tools as an debugging and learning aid is justified. We did not use AI-tools to generate the code of the actual pipeline.


## README file

AI tools were also used to generate the README project file, but it was all manually checked and corrected. 

We think that using AI-tools to generate a first draft of the README file is justified, as long as it is manually checked and corrected.

## For the report 
We also used AI to correct the spelling and grammar in our report but did not ask it for writing the whole report.
